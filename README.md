# AK Screen — descargas

Instaladores oficiales, historial y metadatos de actualización de AK Screen.

Descarga una versión desde [Releases](https://github.com/Edgajuman/AKScreen-Downloads/releases).
En Windows puedes elegir una carpeta distinta para conservar varias versiones.

Este repositorio contiene únicamente distribución y metadatos. El código fuente de AK Screen
se administra en un repositorio privado. Cada paquete incluye sus licencias y atribuciones.

`versions.json` es un catálogo estático que la aplicación consulta mediante HTTPS. No hay servidor
de aplicación, cuentas ni una API propia. Los proyectos y las grabaciones permanecen en el dispositivo.

Los instaladores no están firmados con un certificado comercial. macOS utiliza firma ad hoc.
