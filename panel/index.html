Cómo conectar GitHub

Crea un Fine-grained personal access token con vencimiento y acceso solo a estos repositorios:

  • AKScreen-Control → Contents: Read and write.
  • AKScreen-Builds → Actions: Read and write.

La cuenta debe ser Edgajuman. El permiso Actions permite publicar al momento; si no lo das, los avisos guardados esperan la sincronización programada.

Crear token en GitHub ↗

La clave del panel solo añade un bloqueo a esta interfaz pública. El token de permisos limitados es lo que autoriza a GitHub a editar el repositorio privado. El token no se incluye en la página y permanece en memoria, salvo que elijas guardarlo cifrado en este navegador.
